# LIMITATIONS — 已知限制与研究边界

> 诚实记录系统**不能**做什么，以及哪些结论当前证据不足。任何对外表述都应附带这些限制。

## 1. 数据层

| 限制 | 具体影响 | 缓解 | 是否可消除 |
|---|---|---|---|
| Yahoo 为聚合层 | 价格可能与交易所原始行情有差异；无盘口/成交明细 | 交叉校验关键期限（UST vs CN provider）；文档标注 tier | 需付费/授权源 |
| 期货为前月连续合约 | 展期损益混入收益；期限结构无法直接从主序列得到 | 机制库用月合约另建序列（部分品种）；标注 | 可扩展（分月合约） |
| 缺复权价（部分交易所） | 分红/拆分处理不一致 | 行内记录 NULL，分析退回原始收盘价 | 需其他源 |
| 信用利差用 ETF 代理 | HYG/IEF 相对表现混合久期与利差，非 OAS | 机制/证据中明确标注 proxy；不声称是利差 | 需 ICE/BAML 授权 |
| 无实际利率与盈亏平衡 | "实际利率→黄金"链条只能用名义利率 + TIPS ETF 近似 | 机制 M01/M02 明确证据不足 | 需 FRED/TIPS 数据 |
| Shiller CAPE 止于 2023-09 | 当前美股估值异常无法判断 | 系统判定陈旧并停用，报告列出 | 需其他估值源 |
| Eurostat 镜像止于 2025-12 | 欧元区通胀实时判断缺失 | 同上 | 需其他镜像 |
| BLS 缺 2025-10 CPI | YoY 断点 | 记录缺口，不插值 | 上游缺失 |
| 中国宏观仅季度/月度代理 | 无法及时捕捉社融/PMI/地产冲击 | 用国债曲线、CNH、行业 ETF 价格补充 | 需中国官方/商业源 |
| 无分析师预期 | "预期差"的盈利维度无法验证 | 写入每个机会的 open_questions | 需付费一致预期数据 |
| 无期权隐含分布 | 事件预期差大小无法量化 | 事件原型仅作线索，不作方向判断 | 需期权数据 |
| 无 ETF 资金流 | 仓位判断只有 CFTC 期货 | 标注覆盖范围 | 需 EPFR 等 |

## 1b. 已修复并加回归测试的问题（2026-11-14 audit）

- CFTC 前视与 net/OI 归一化；宏观可用日与频率窗口；历史回放逐日切片。
- 周一/节假日后收益丢失；trend_break 假突破；市场广度因窗口口径失效；盘中未完成 K 线。
- 非标准份额折算（3.213:1）误导出的 520 行隔离；BLS/BIS 修订未回补。
- 预期差用可测代理替换常数；缺失数据不得升为重点研究；评分重复计入；机制统计无多重检验校正。
- 下游语义失败被误判为成功；数据失效仍生成机会；自动评分不能降级。

## 2. 方法层

1. **异常 ≠ 错误定价。** 稳健 z/分位只说明"不寻常"；机会层要求机制或背离论证 + 证据门槛，
   但仍不能证明市场错误。所有机会都是**待检验假设**。
2. **相关性 ≠ 因果。** 传导机制的检验是历史共动与条件统计，无法识别因果；每份机制证据都带
   `identification: correlation_only` 与成立条件/反证条件。
3. **条件收益是描述性的。** 样本重叠、制度变化、选择偏差都会影响；不作预测，不构成收益承诺。
4. **评分衡量研究优先级。** 权重是先验设定，未用未来收益拟合；高分不代表高收益或高胜率。
5. **主题归并可能掩盖差异。** 同一主题只保留最高分候选（如 GC vs GLD），可能丢失不同包装的
   流动性/税收/合约差异；深度研究阶段需重新审视具体标的。
6. **事件日历不完整。** 仅官方可核验日期；中国 LPR 为约定规则（verified=false），财报日历缺失。
7. **回放窗口有限。** 2014/2015 起的数据无法覆盖 2008 危机、2011/2015 等更早结构；
   数据源自身的历史也在起点处可能有修订。
8. **预期差只是代理，不是市场共识。** 系统没有一致预期或期权隐含分布数据；`expectation_gap` 由仓位、估值与驱动残差构成，残差回归无法识别因果，R² 低时直接标为不可用。任何"预期差"结论都必须回到这三项证据审视。
9. **机制统计仍非因果识别。** p 值与 BH-FDR 只控制"共动是否偶然"，不解决遗漏变量、制度变化与反向因果；lead-lag 只是方向性描述。
10. **研究质量评价是 LLM 盲评，不是人类专家标签，也不是前瞻收益检验。** 它只能说明"在给定事实下研究对象是否更有研究价值"，不能证明筛选能带来投资收益。
11. **状态机是规则化的。** 45 天未复现即过期、失效条件自动触发；这会有误判（例如长期结构性机会被过期）。
12. **幸存者偏差。** 标的池由当前仍在交易/存续的指数、ETF 与期货构成；已退市 ETF、已停止发布的指数、
   已下架的期货合约不在池中。因此历史广度、相对强弱与回放结果存在幸存者偏差，不能解释为"当时可投资
   全集的真实表现"。当前无法消除，只能显式声明。
13. **指数/ETF 成分变化。** 宽基指数与行业 ETF 的成分股随时间变化（如 GICS 行业重分类），历史价格
    反映的是"当前指数定义"的回溯，不是当时的成分。

## 3. 覆盖层

- **第一优先级**（美国、中国大陆）数据最完整；**第二/三优先级**（香港、日本、欧洲、其他 EM）
  主要是价格/指数/ETF，缺少本地宏观与信用数据。
- 商品覆盖价格与持仓，不覆盖库存、产量、天气、航运。
- 加密资产仅 BTC/ETH/SOL 价格，无链上数据、资金费率、交易所流量。
- 波动率仅 VIX/VIX3M/VVIX/MOVE/SKEW 指数，无期权曲面。

## 4. 工程层

- 单用户、单机 SQLite；未做多进程写入隔离与高可用。
- 网络依赖：数据源限速/封禁会导致部分运行失败；系统记录并继续，但不保证每次全量成功。
- 未做浏览器端到端测试（仪表盘仅服务端渲染 + JSON API 冒烟）。
- 未接入 CI；测试需本地运行（`.venv/bin/python -m pytest`）。
- 期货合约月份解析依赖 Yahoo 符号规则；新合约需在 `config/` 中登记。
- 回放较慢（每个 as_of 重建特征，约 30–120 秒），三年逐月回放需数十分钟。

## 5. 合规与边界

- 不连接券商/交易账户，不下单，不提供投资建议或收益承诺。
- 不抓取付费墙内容，不使用未授权数据；Yahoo 数据仅用于个人研究。
- 不把研究结论包装为"确定机会"；每条记录必须携带反对证据与失效条件。

## 6. 如果要把系统用于真实决策，还缺什么

1. 授权数据：OAS 信用利差、实际利率/盈亏平衡、分析师一致预期、ETF 资金流、期权隐含分布。
2. 行业/公司层面的基本面数据与财报日历。
3. 更严格的统计识别（工具变量、事件研究、状态空间模型）与多重检验校正。
4. 人工复核流程：每条 deep_research 机会需研究员签字确认证据链，再进入投资决策。
5. 绩效归因：把"发现"与"研究质量"与"投资收益"分开评估，避免把检测能力误当盈利能力。
